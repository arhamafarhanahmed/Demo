# Itech Design — Redesign Pitch Demo

Premium single-page marketing site for **Itech Design**, an advanced digital studio specializing in web design, HD/SD video, 3D animation, and digital signage.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
